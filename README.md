# 本轮增量（15 个文件）

在已经套用过上一个包的仓库里，按路径覆盖同名文件即可，路径和仓库一致。

- Webhook 网址改为普通文本框并显示已保存的值；签名密钥可以点眼睛查看（服务端把这四个值列给超级管理员）
- 异常用量告警新增"时区（相对 UTC 的小时数）"，默认 0；日和月从该时区的零点开始，卡片脚注写明时区
- 页面改为"改了什么就保存什么"，清空地址或密钥再保存即清除；去掉"移除"按钮

    go build ./... && go vet ./...
    go test ./pkg/larknotify/ ./i18n/
    cd aurora && bun run typecheck
